How to set up DivPic in Firefox

Updated October 26, 2026
On this page

    DivPic installs from Firefox Add-ons. Firefox is stricter than Chrome about which sites an extension can read, so there's one permission to check.

    What you need
    • A Mac, Windows or Linux computer
    • Desktop Firefox 140 or later

    Install DivPic

    1. Open DivPic on Firefox Add-ons.
      Add to Firefox
    2. Click Add to Firefox, then Add.
    3. Reload any tab that was already open. Pages loaded before the install don't have DivPic yet.

    Give DivPic access to websites

    Firefox lets you switch off an extension's access to websites, and DivPic can't read the element you click without it.

    1. Open about:addons (or Menu → Add-ons and themes) and click DivPic.
    2. Open the Permissions tab.
    3. Turn on Access your data for all websites if it's off.
    Page access is only used to read the element you click. Screenshots are made on your computer and never uploaded. See the privacy policy.

    Pin it to the toolbar

    Click the puzzle-piece Extensions icon in the toolbar, open the gear next to DivPic, and choose Pin to Toolbar.

    Start capturing

    Click the DivPic button, or press ⇧ ⌘ E on Mac (Ctrl ⇧ E on Windows and Linux). From there, see screenshotting an element or copying into Figma.

    Change the shortcut

    Open about:addons, click the gear icon at the top, and choose Manage Extension Shortcuts. Set a new one for Start element selection under DivPic.

    Troubleshooting

    The DivPic button does nothing

    Reload the page, then check that Access your data for all websites is on under about:addons → DivPic → Permissions. Firefox also blocks every extension on about: pages and addons.mozilla.org, so try a regular website.

    DivPic doesn't work in private windows

    Firefox keeps extensions out of private windows by default. Open about:addons, click DivPic, and set Run in Private Windows to Allow.

    The shortcut doesn't work

    Another add-on may already use it. Open Manage Extension Shortcuts from the gear menu in about:addons and give DivPic a free combination.

    Which Firefox version do I need?

    Desktop Firefox 140 or later. Firefox for Android isn't supported.
