How to set up DivPic in Safari on Mac

Updated October 17, 2026
On this page

    Safari extensions ship inside a Mac app, and Safari keeps them switched off until you say otherwise. Setup takes about a minute.

    What you need
    • A Mac running macOS 13 Ventura or later
    • Safari

    Install and turn on DivPic

    1. Install DivPic from the Mac App Store.
      Get it on the Mac App Store
    2. Open the DivPic app once. This registers the extension with Safari.
    3. In Safari, open Settings → Extensions and tick DivPic.

    Allow DivPic on websites

    Safari asks before any extension can read a page. You can allow DivPic site by site, or everywhere at once.

    OptionWhat it meansGood for
    AskSafari asks the first time you use DivPic on each siteUsing DivPic on a handful of sites
    AllowDivPic works on that site without asking againSites you capture from often
    Allow on all websitesDivPic works everywhereDesigners and developers who capture all day

    Change this any time in Safari Settings → Websites → DivPic.

    DivPic needs page access to read the element you click. Screenshots are still made on your Mac and never uploaded. See the privacy policy.

    Start capturing

    Click the DivPic button in Safari's toolbar, or press ⇧ ⌘ E. From there it works the same as on Chrome and Firefox: see screenshotting an element or copying into Figma.

    Troubleshooting

    The DivPic button does nothing

    Reload the page. Tabs that were open before DivPic was turned on don't have it yet. Also check that DivPic is allowed on that site in Safari Settings → Websites → DivPic.

    I can't find DivPic in Safari's Extensions list

    Open the DivPic app from your Applications folder once, then look again. Safari only lists an extension after its app has been opened.

    Which macOS version do I need?

    macOS 13 Ventura or later.
