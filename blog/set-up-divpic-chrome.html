How to set up DivPic in Chrome

Updated October 26, 2026
On this page

    DivPic installs from the Chrome Web Store in one click. The same listing works in Arc, Edge, Brave and every other browser built on Chromium.

    What you need
    • A Mac, Windows or Linux computer
    • Chrome, or a Chromium browser such as Arc, Edge or Brave

    Install DivPic

    1. Open DivPic on the Chrome Web Store.
    2. Click Add to Chrome, then Add extension. Edge may first ask you to Allow extensions from other stores.
    3. Reload any tab that was already open. Pages loaded before the install don't have DivPic yet.

    Pin it to the toolbar

    Chrome tucks new extensions behind the puzzle-piece Extensions icon. Pin DivPic so it's one click away.

    1. Click the puzzle-piece icon to the right of the address bar.
    2. Click the pin next to DivPic.

    Start capturing

    Click the DivPic button, or press ⇧ ⌘ E on Mac (Ctrl ⇧ E on Windows and Linux). From there, see screenshotting an element or copying into Figma.

    DivPic needs access to the page to read the element you click. Screenshots are made on your computer and never uploaded. See the privacy policy.

    Change the shortcut

    If ⇧ ⌘ E clashes with something else, open chrome://extensions/shortcuts and set a new one for Start element selection under DivPic.

    Troubleshooting

    The DivPic button does nothing

    Reload the page. Tabs that were open before DivPic was installed don't have it yet. Chrome also blocks every extension on chrome:// pages, the new tab page and the Chrome Web Store, so try a regular website.

    DivPic doesn't work in Incognito

    Chrome turns extensions off in Incognito by default. Open chrome://extensions, click Details under DivPic, and turn on Allow in Incognito.

    The shortcut doesn't work

    Another extension or app may already use it. Check chrome://extensions/shortcuts and give DivPic a free combination.

    Does DivPic work in Arc, Edge and Brave?

    Yes. Any browser built on Chromium installs DivPic from the Chrome Web Store, and the steps above are the same.
